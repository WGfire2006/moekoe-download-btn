# 为MoeKoe播放栏增加下载按钮
在 MoeKoe Music 播放栏增加一个下载按钮，一键下载当前播放的歌曲。
## 功能
- 播放栏右侧注入下载按钮
- 点击即可下载当前播放歌曲（自动获取歌名、歌手、音频链接）
- 右键按钮可选择功能：下载当前歌曲 / 复制歌曲名 / 复制下载链接 / 查看下载历史
- 下载进度动画 + Toast 通知
- 自动记录下载历史（最多 50 条）
## 安装方法:
### 方法一：手动安装
1. 将整个 `moekoe-download-btn` 文件夹复制到 MoeKoe Music 的插件目录：
2. 重启 MoeKoe Music 即可
### 方法二：应用内安装
1. 打开 MoeKoe Music
2. 进入「插件管理」页面
3. 点击「安装本地插件」
4. 选择 `moekoe-download-btn.zip` 文件（zip内结构应为文件夹包含多个文件形式）
